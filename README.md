# BlockVote: Blockchain-Based Automated Voting System for Secure and Transparent Elections

This repository contains the source code for our thesis project, **BlockVote**, a blockchain-based automated voting system designed to provide secure, transparent, and tamper-resistant elections.

To promote **transparency and accountability**, the source code is publicly available for review, allowing stakeholders, candidates, and auditors to inspect how votes are processed, validated, and recorded. This ensures that election results can be independently verified in case of disputes or concerns regarding election integrity.
